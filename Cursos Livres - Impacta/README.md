# Cursos Livres — Impacta

Este diretório reúne cursos livres e de extensão realizados na Impacta, com foco em prática de mercado, ferramentas de dados e fundamentos de linguagem.

## Cursos disponíveis

- [ETL na Prática — Como Trabalhar com Dados (online)](./ETL%20na%20Prática%20-%20Como%20Trabalhar%20com%20Dados%20(online)/) — pipeline completo de extração, transformação, carga e análise de dados em Python.
- [Java Programmer - IMPACTA - MY WAY](./Java%20Programmer%20-%20IMPACTA%20-%20MY%20WAY/) — fundamentos da linguagem Java, tipos, estruturas básicas e introdução à programação orientada a objetos.

## Objetivo pedagógico

O conjunto busca conectar a formação acadêmica com demandas reais de mercado, com foco em:

- engenharia de dados e ETL;
- análise de dados com Python;
- linguagem Java e raciocínio orientado a objetos.

## Como navegar

- Comece pelo curso de interesse.
- Leia os READMEs internos para entender a ordem de execução dos materiais, notebooks e projetos.
- Use os materiais como trilha prática para reforçar conceitos em análise e desenvolvimento.
