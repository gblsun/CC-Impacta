# Convenções do repositório

## Novos conteúdos

Para manter o acervo portável entre Windows, Linux, URLs e automações, novos diretórios e arquivos devem usar nomes em `kebab-case`, sem espaços, acentos ou caracteres especiais. Exemplo:

```text
05-semestre/teoria-dos-grafos/floyd-warshall/
```

O acervo histórico preserva os nomes originais; esta regra vale para conteúdo novo ou para uma migração planejada, evitando quebrar links existentes.

## Dados e artefatos grandes

Não versione instaladores, ambientes virtuais, vídeos, datasets grandes ou saídas geradas. No README do projeto, informe a fonte, licença e instruções de obtenção. Quando o arquivo for indispensável e grande, use Git LFS.

## README de projeto

Todo projeto que for apresentado deve informar: objetivo, tecnologias, como executar, resultado e próximos passos.
