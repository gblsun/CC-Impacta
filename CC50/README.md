# CC50

Este diretório reúne exercícios e fundamentos da linguagem C desenvolvidos a partir do curso [CS50](https://cs50.harvard.edu/) da Harvard University.

## Objetivo

Reforçar lógica de programação, sintaxe básica em C, estruturas de controle e familiaridade com a linguagem de baixo nível, com enfoque em solução de problemas simples e introdução à programação estruturada.

## Estrutura

- `Módulo 1 - C/` — exercícios introdutórios em C, incluindo o arquivo `hello.c` e outros programas básicos.

## Como explorar

- Abra a pasta do módulo e leia os arquivos em sequência.
- Use os programas como referência para revisão de sintaxe, entrada e saída, condicionais, loops e organização de código.

Este material complementa o aprendizado do repositório principal e funciona como um ponto de partida para práticas em linguagem C.
