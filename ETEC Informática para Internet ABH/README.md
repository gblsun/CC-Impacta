# ETEC — Informática para Internet

Este diretório reúne materiais trabalhados no curso técnico em Informática para Internet, com foco em desenvolvimento web, lógica de programação, estruturas de projetos e interfaces digitais.

## Disciplinas e projetos

- [Programação e algoritmos](./Programação%20e%20algoritmos/) — lógica de programação em C, com programas como calculadora, tabuada e IMC.
- [Gestão e conteúdo Web](./Gestão%20e%20conteúdo%20Web/) — gestão de conteúdo para web.
- [Interfaces Web](./Interfaces%20Web/) — HTML, CSS e práticas de interface visual.
- [Projeto Prático](./Projeto%20Prático/) — site temático sobre estilos musicais.
- [Projeto Menu](./Projeto%20Menu/) — estrutura de menu web.
- [Projeto Cripto](./Projeto%20Cripto/) — projeto relacionado a criptomoedas.
- [Projetos com DreamWeaver](./Projetos%20com%20DreamWeaver/) — sites produzidos com o Adobe DreamWeaver.
- [site ti é aqui](./site%20ti%20é%20aqui/) — site institucional fictício de loja de tecnologia.

## Objetivo

Compreender a base do desenvolvimento front-end, a organização de conteúdos digitais e a lógica de criação de páginas e sistemas web simples.

## Perfil de uso

Este material é útil para consultas rápidas de HTML, CSS, organização visual e trabalho com páginas estáticas e estruturadas.
