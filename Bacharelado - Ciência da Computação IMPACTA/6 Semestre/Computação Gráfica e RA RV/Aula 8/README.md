# Galeria 3D: instâncias e hierarquia

Uma cena interativa em Pygame que demonstra reutilização de malha, transformações 3D, câmera orbital e composição pai-filho.

## Tecnologias

Python e Pygame.

## Problema abordado

Demonstrar como uma única malha pode gerar vários objetos com transformações próprias e como objetos filhos herdam posição e rotação de um objeto pai.

## Como executar

1. Instale Python 3.11 ou superior.
2. Execute `python -m pip install pygame`.
3. Execute `python aula8-galeria-3d.py` a partir deste diretório.

Use `1` a `4` para selecionar objetos, as setas para controlar a câmera, `Espaço` para alternar sólido/arame e `Esc` para sair.

## Resultado e aprendizados

A galeria exibe instâncias com escala, posição e rotação independentes e um pedestal com placa filha. As decisões de modelagem e as respostas de reflexão estão em [Galeria 3D - instanciacao e hierarquia de objetos.md](Galeria%203D%20-%20instanciacao%20e%20hierarquia%20de%20objetos.md).
